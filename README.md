# Oficina Mecânico (iOS)

App SwiftUI para o **mecânico** ver a esteira e atualizar os carros atribuídos a ele. O pátio completo e a atribuição de mecânicos ficam na [web do gerente](https://github.com/RenanAlvesBCC/oficina-web).

## Documentação

- [Visão](docs/VISAO.md)
- [Glossário](docs/GLOSSARIO.md)
- [Roadmap](docs/ROADMAP.md)
- [Contrato da API](docs/CONTRATO-API.md)

Antes de implementar: leia `AGENTS.md` e o skill `.cursor/skills/implementar-feature`.

## Stack

SwiftUI, MVVM, SwiftData (cache + fila offline), Keychain, Face ID / Touch ID. Target iOS 26. API em debug: `http://localhost:8080`.
